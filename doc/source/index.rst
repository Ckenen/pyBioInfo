Welcome to pyBioInfo's documentation!
=====================================

**pyBioInfo** is a package for bioinformatics analysis, providing
tools for genomic interval manipulation, biological file formats
I/O, coordinate systems conversion, and more.

.. note::
   This documentation is under active development. The Range classes
   and BlockTools are documented first; other sections will be added
   later.
